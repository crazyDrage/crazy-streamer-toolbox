You don't have to start from nothing.

- **Connections → Twitch** (or YouTube, ...) → **Add default flows**: thanks for a follow, a raid with a
  shoutout, a `!so` command, ... They go into a folder of their own, e.g. **Twitch - default**, each named with the connection first ("Twitch - default - thank a follow").
- **Learn → Examples** → **Add to my flows**: a copy of that page's example, in the folder **Examples**.

Both come in **switched off**, so nothing happens on stream that you didn't switch on. Open one, change the
words to yours, then switch it on.

Pressing the button again brings back only the flows missing from the folder. One you changed stays as it is.

**Share your own:** Flows → open a folder → **Export folder** gives one file with its flows. **Import** on the
Flows page reads it on another toolbox.
