crazy-streamer-toolbox

This software is made with the help of AI: the code is written with Claude Code. It is a work in progress and still needs testing.

One program for the things a stream needs glued together: buttons that do something in OBS, VTube Studio, SAMMI, Mix It Up or on Twitch, flows that run when a viewer follows, subscribes or redeems, and alerts and widgets on stream. You build everything by clicking; no code.

It runs on your own PC and shows its pages in a window or in your browser. Nothing is sent to a server of ours: there is none.
